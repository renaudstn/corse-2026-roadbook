# Corse 2026 — Roadbook

Site web familial pour le voyage en Corse du **3 au 16 août 2026**.

## Utilisation

- Ouvrir le site sur le téléphone (idéalement « Ajouter à l’écran d’accueil »)
- Fonctionne **hors ligne** après la première ouverture (PWA)
- Bouton **Aujourd’hui** pour aller au jour en cours
- Check-list sauvegardée localement sur l’appareil

## Contenu

- Programme jour par jour (horaires, vigilance, plan B)
- Campings L’Acciola, Chez Bartho, Abbartello (dates inchangées)
- Contacts appelables en un tap
- Logistique carburant / courses / enfants / chaleur

## Technique

Site statique (HTML / CSS / JS) conçu pour GitHub Pages.
